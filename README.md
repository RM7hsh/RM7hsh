## Featured Projects

### [ansible-monitoring-automation](https://github.com/RM7hsh/ansible-monitoring-automation)
Ansible automation for Prometheus, Grafana, Linux node_exporter and Windows exporter. The project focuses on adding Linux/Windows hosts to monitoring, updating scrape targets, configuring firewall rules and automating monitoring stack deployment.

### [redos-itplanet-ansible-lab](https://github.com/RM7hsh/redos-itplanet-ansible-lab)
Ansible-based RED OS lab for competition-style infrastructure tasks: Samba AD DC, domain users, DHCP, SSH hardening, Samba file server, iRedMail/SOGo, Squid, Nextcloud and firewalld.

### [terraform-ansible-docker-lab](https://github.com/RM7hsh/terraform-ansible-docker-lab)
Terraform + Ansible lab for Proxmox and Docker infrastructure. Terraform creates virtual machines, while Ansible installs Docker, deploys Compose stacks, runs a local Docker Registry and manages runtime hosts.

### [linux-server-baseline-check](https://github.com/RM7hsh/linux-server-baseline-check)
Bash utility for basic Linux server health checks: hostname, IP address, default gateway, root filesystem usage, SSH status and QEMU Guest Agent status.
